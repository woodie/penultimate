# penultimate v0.1.1

## First npm release

`justBeforeEach` for Vitest 4.1 and later 4.x releases, now on npm under its
new name:

```
npm install --save-dev penultimate
```

```js
import { justBeforeEach } from 'penultimate'
```

The code is the same as `v0.1.0`. That tag was cut before the rename, so it
still installs as `qvick`; this is the first release published as
`penultimate`.

## What it does

A `justBeforeEach` step runs after every `beforeEach` at every nesting
level, outermost first, right before the test. Set inputs in each
`context`'s own `beforeEach`, and write the action under test once, in the
parent. It works with Vitest's own `it`, so `it.each`, `it.skip`, `it.only`,
`it.fails`, `it.concurrent` and `retry` all behave as usual.

## Upgrading from `v0.1.0`

Replace the GitHub dependency with the npm one, and change the import from
`qvick` to `penultimate`:

```
npm uninstall qvick
npm install --save-dev penultimate
```

## Releases from here on

Each `v*` tag now publishes to npm from GitHub Actions, using npm's trusted
publishing, so no npm token is stored anywhere.
